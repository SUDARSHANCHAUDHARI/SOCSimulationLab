# Security Notes

This project is defensive and lab-only.

## Safe Use

- Use only synthetic logs or logs from systems you own or have permission to assess.
- Do not commit real incident data, customer logs, credentials, tokens, private IP maps, or exploit payloads.
- Treat generated reports as sensitive because they document visibility gaps.

## Scope

The repository does not scan, exploit, or connect to external systems. It only compares local synthetic events to expected SOC signals.

## Before Sharing

Review:

- collected events
- scenario files
- generated reports
- screenshots or terminal recordings
